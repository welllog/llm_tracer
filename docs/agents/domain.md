# Domain Documentation

This repository follows a **single-context** layout for domain documentation.

## Layout

- **Root Context**: `CONTEXT.md` at the repository root.
- **Architectural Decisions**: `docs/adr/` directory for ADRs.

## Consumer Rules

Skills like `improve-codebase-architecture`, `diagnosing-bugs`, and `tdd` should:
1. Read `CONTEXT.md` for domain language and system overview.
2. Consult `docs/adr/` for historical context and past decisions.
