# Triage Labels

This repository uses a standard set of triage labels to manage the lifecycle of issues.

## Label Mapping

The following roles are mapped to these specific label strings:

| Role | Label | Description |
|------|-------|-------------|
| `needs-triage` | `needs-triage` | Needs maintainer evaluation |
| `needs-info` | `needs-info` | Waiting on more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AI agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |
